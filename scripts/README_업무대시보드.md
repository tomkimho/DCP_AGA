# 주간 업무 현황판 생성기

주간 업무보고 문서(Google Docs)를 단일 HTML 대시보드로 변환한다.

## 실행

```bash
# 1. Google Docs → 마krdown 내려받기 (파일 → 다운로드 → Markdown)
# 2. 대시보드 생성
python3 scripts/13_업무대시보드.py 주간업무보고.md -o output/업무대시보드.html --stamp 2026-08-19
```

의존성 없음(표준 라이브러리만 사용). 결과물은 외부 요청이 없는 단일 HTML 파일이라
파일을 열기만 하면 되고, 폰트만 Google Fonts에서 받아온다.

## 입력 문서가 갖춰야 할 구조

```
# 2026-08-19
2026-08-19 (수)
★발표순서: 홍길동>김철수>...

|  | 진행 현황 | 진행 계획 |
| ○○사업본부(홍길동) | 1. 매출**(A사)** ○2차: ... | 1. 매출 ... |
| ○○개발본부(김철수) | ...                       | ...        |

○ 이슈사항
- ...
○ 대표님 지시사항
- ...
```

- `# YYYY-MM-DD` 제목이 회차 하나를 연다. 다음 `# ` 제목까지가 그 회차 범위다.
- 표의 첫 열이 `조직명(담당자)`, 둘째·셋째 열이 진행 현황·진행 계획이다.
  한 셀이 여러 줄로 쪼개진 행(첫 열이 빈 행)은 위 조직에 이어 붙는다.
- 셀 본문은 `1. 매출 / 2. 정부지원사업 / 3. 기술개발 / 4. 영업·마케팅·행사 / 5. 기타`
  로 나뉜다. 번호가 1부터 순서대로 올라가는 것만 구분자로 인정한다.
- `**(A사)**`처럼 굵게 표기한 이름을 프로젝트 단위로 잡고, 다음 굵은 이름이
  나올 때까지의 항목을 그 건에 귀속시킨다.

## 화면 구성

| 화면 | 내용 |
| --- | --- |
| 전체 요약 | KPI, 조직 x 회차 활동량 히트맵, 영역별 보고 비중 |
| 회차별 보고 | 회차를 골라 조직별 진행 현황·계획을 원문 그대로 확인 |
| 프로젝트 추적 | 고객사·정부과제·기술·행사 단위 집계, 행을 누르면 이력 패널 |
| 이슈·지시사항 | 항목 단위로 묶은 등록부, 연속 회차 길이로 정체 건 식별 |

주간보고는 같은 문장이 몇 주씩 이월되는 특성이 있어, 이력 패널과 이슈 등록부는
반복 문구를 한 줄로 접고 `22회 동일 기재`처럼 몇 회차째인지를 표시한다. 여기서
연속 회차가 길다는 것은 해당 건이 그만큼 오래 같은 상태로 남아 있다는 뜻이다.

## 보안

입력 문서와 생성된 HTML에는 고객사·계약·인사 정보가 들어 있다. 이 저장소는
공개 저장소이므로 **생성기 코드만 커밋하고 문서와 결과물은 커밋하지 않는다.**
`output/`, `*주간업무*` 경로는 `.gitignore`로 막아 두었다.
