============================================================
  지금 당장 할 일 (1주차)
============================================================

[Step 1] Python 설치
  - https://www.python.org/downloads/ 접속
  - "Download Python 3.12" 버튼 클릭
  - 설치 시 ★반드시★ "Add Python to PATH" 체크!
  - 설치 완료

[Step 2] VS Code 설치
  - https://code.visualstudio.com/ 접속
  - Download 클릭 → 설치
  - 설치 후 왼쪽 확장(Extensions) 탭에서:
    "Python" 검색 → 설치
    "Korean Language Pack" 검색 → 설치

[Step 3] 라이브러리 설치
  - 윈도우키 + R → "cmd" 입력 → 확인 (명령 프롬프트 열림)
  - 아래 명령어를 한 줄씩 복사해서 붙여넣기 후 엔터:

    pip install pandas openpyxl pdfplumber

  - "Successfully installed" 나오면 성공!

[Step 4] 환경 테스트
  - cmd에서 아래 명령어 실행:

    cd "PDF가 있는 폴더 경로\scripts"
    python 00_환경테스트.py

  - 모두 "OK"가 나오면 1주차 완료!


============================================================
  2주차에 할 일
============================================================

  cmd에서:
    cd "PDF가 있는 폴더 경로\scripts"
    python 01_pdf_추출.py

  → 2-3시간 기다리면 716건의 텍스트가 자동 추출됩니다.
  → 추출된 파일은 txt_추출결과 폴더에 저장됩니다.
